## 3. Strategic Roadmap & Milestones

### Phase 1: Core IDE Fidelity & Portfolio Foundation (Completed)
- [x] High-fidelity VS Code layout (ActivityBar, Sidebar, Breadcrumbs, Tabs, Status Bar).
- [x] Dynamic theme engine (5 IDE themes + customizable accent presets).
- [x] Comprehensive experience timeline including **CybrCraft**, **Deen Commerce**, **NZ TEX**, **Daraz**, and **Gear Master**.
- [x] Full interactive POSIX terminal with mock filesystem and command processing.
- [x] Interactive project case studies with Git Diffs and deployment metrics.

### Phase 2: AI Copilot & Knowledge Graph Integration (Current)
- [x] Local deterministic intelligence engine (`intelEngine.ts`) for instant answers.
- [x] Vector embedding retrieval pipeline with Pinecone and Google Gemini / Anthropic.
- [x] Direct live links for CybrCraft (https://cybrcraft.com/) and client projects.
- [x] Real-time command palette search (`Ctrl+P`) indexing files, skills, and case studies.

### Phase 3: Interactive Sandbox & Live Telemetry (Next Steps)
- [ ] Interactive Python / SQL code sandbox directly inside the browser terminal.
- [ ] Live analytics dashboard showing anonymized portfolio traffic and interaction heatmaps.
- [ ] Automated client booking and project estimation tool powered by CybrCraft.
- [ ] Offline PWA capabilities for instant resume and project browsing without connectivity.
